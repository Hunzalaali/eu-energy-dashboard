# EU Energy Dashboard

This is a web application built with React, Vite, and TypeScript.

## Prerequisites

- Node.js
- npm (Node Package Manager)

## How to Run Locally

1. **Install Dependencies**
   Navigate to the project directory and install the required npm packages:
   ```bash
   npm install
   ```

2. **Start the Development Server**
   Run the following command to start the Vite development server:
   ```bash
   npm run dev
   ```
   This will start the app locally, and you can view it in your browser (typically at `http://localhost:5173`).
